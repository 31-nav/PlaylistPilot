PlaylistPilot — Smart Playlist & Batch Job Manager

Your Playlist. Your Queue. Your Control.

PlaylistPilot is an MCA-level Python software engineering project designed to solve the challenges of managing, queueing, and processing large educational playlists (100+ videos). It combines a robust local-first architecture, an ACID-compliant SQLite datastore, a dedicated single-worker queue engine, and deterministic crash recovery mechanisms.

1. Persistent Queue Engine

A dedicated background worker thread processes items sequentially using FIFO and priority ordering. Urgent jobs can be prioritized to the front of the waiting queue without disrupting the active job.

2. Fault & Restart Recovery

On application startup or sudden power loss, orphaned active jobs are safely inspected, preserved if completed, or marked as interrupted/requeued without repeating completed work.

3. Multi-Resolution Media Engine

Powered by yt-dlp and FFmpeg, allowing users to choose video resolutions (1080p, 720p, 480p, 360p) or extract clean MP3 audio directly to custom local disk folders.

Technology Stack

  • Backend: Python 3.11+, Flask Application Factory, SQLAlchemy ORM, SQLite datastore.
  • Media Engine: yt-dlp & FFmpeg for high-speed multi-format stream extraction and local storage.
  • Concurrency: Standard library threading.Thread with threading.Lock and threading.Event.
  • Frontend: Semantic HTML5, Vanilla CSS with custom 3D depth system, Vanilla JavaScript Fetch API.
  • Visual Identity: Strict four-color palette: Black (#111111), Red (#E62117), Gray (#808080), White (#FFFFFF).
  • Test Suite: 38 automated test cases covering models, queue, API, storage, and worker services.
Production & Deployment Note:
PlaylistPilot is designed to run self-hosted on any system or web service. All downloads and state transitions persist in an ACID-compliant local database, giving users full ownership and offline access to their media library.
